# OBJETIVO
Extraer TODAS las garantías exigidas al oferente o al adjudicatario.
Cada garantía distinta es un ítem del array. No las agrupes.

# ESQUEMA
{
  "garantias": [
    {
      "tipo": "mantenimiento_oferta|cumplimiento_contrato|anticipo|impugnacion|otra",
      "monto_porcentaje": <número o null>,
      "monto_valor": <número o null>,
      "moneda": "ARS|USD|EUR|otra" o null,
      "base_calculo": "porcentaje|monto_fijo|no_especificado",
      "sobre_que_se_calcula": "presupuesto_oficial|monto_ofertado|monto_adjudicado|otro" o null,
      "forma_constitucion": "poliza_caucion|aval_bancario|deposito|cheque_certificado|pagare|titulos_publicos|otra" o null,
      "plazo_constitucion": <texto literal del pliego o null>,
      "vigencia": <texto literal del pliego o null>,
      "confidence": <número calculado según la rúbrica del sistema>,
      "source_references": [
        {
          "document_id": <valor exacto del header del fragmento>,
          "page_number": <valor exacto del header del fragmento>,
          "citation": <subcadena literal del fragmento>
        }
      ],
      "extraction_status": "success|partial|not_applicable|not_found"
    }
  ]
}

# REGLAS ESPECÍFICAS
- `monto_porcentaje` y `monto_valor` son excluyentes.
  "5% del presupuesto oficial" → `monto_porcentaje: 5.0`, `monto_valor: null`,
  `base_calculo: "porcentaje"`, `sobre_que_se_calcula: "presupuesto_oficial"`.
  "$ 150.000" → `monto_valor: 150000.0`, `monto_porcentaje: null`,
  `base_calculo: "monto_fijo"`, `moneda: "ARS"`.
- Números: sin separador de miles, punto decimal. `AR$ 1.250.000,50` → `1250000.5`.
- NO infieras moneda. Un porcentaje sin importe no tiene moneda → `null`.
  Solo poné `"ARS"` si el pliego escribe `$`, `AR$`, `pesos` o `ARS`.
- Sinónimos frecuentes de `mantenimiento_oferta`: garantía de oferta, seriedad de
  la oferta, garantía de la propuesta, caución de oferta.
- Si el pliego menciona la garantía pero no su monto → `extraction_status: "partial"`,
  no `success`.
- Si el pliego dice explícitamente que no se exige garantía (ej: "no se requerirá
  garantía de mantenimiento de oferta"), emití el ítem con
  `extraction_status: "not_applicable"` y la cita de esa frase.
- `plazo_constitucion` y `vigencia` son texto literal, no fechas calculadas.
