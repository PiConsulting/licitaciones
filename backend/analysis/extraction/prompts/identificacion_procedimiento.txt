# OBJETIVO
Extraer los datos identificatorios del procedimiento: quien llama, bajo que numero
de expediente y procedimiento, con que modalidad y en que jurisdiccion.

# ESQUEMA
{
  "identificacion_procedimiento": [
    {
      "tipo": "organismo_convocante|expediente|numero_procedimiento|tipo_procedimiento|jurisdiccion|normativa_aplicable|unidad_operativa",
      "valor": "<texto literal del pliego>",
      "metadata": {},
      "confidence": "<numero calculado segun la rubrica del sistema>",
      "source_references": [
        {
          "document_id": "<valor exacto del header del fragmento>",
          "page_number": "<valor exacto del header del fragmento>",
          "citation": "<subcadena literal del fragmento>"
        }
      ],
      "extraction_status": "success|partial|not_applicable|not_found"
    }
  ]
}

# REGLAS ESPECIFICAS
- Un item por dato. No armes un objeto unico con todo.
- `organismo_convocante`: nombre completo del ente que llama. Si aparece una unidad operativa de compras, emitila aparte como `unidad_operativa`.
- `expediente` y `numero_procedimiento` son distintos.
- `tipo_procedimiento`: copiar termino literal (licitacion publica, privada, contratacion directa, etc.).
- `normativa_aplicable`: incluir referencia completa (ley/decreto/reglamento) cuando exista.
- Si los datos vienen en tabla, `citation` con formato: `Encabezado: <col> | Fila: <fila> | Valor: <valor>`.

# EJEMPLO DE AUSENCIA
{"identificacion_procedimiento":[]}

{chunks}
=== FIN DEL CONTENIDO ===
