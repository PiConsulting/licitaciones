# OBJETIVO
Extraer requisitos de admisibilidad del oferente en una sola categoría:
documentos respaldatorios y restricciones/condiciones habilitantes.
Un ítem por requisito.

# REGLAS ESPECÍFICAS
- `documento`: certificados, formularios, balances, constancias o antecedentes que
  el pliego exige presentar.
- `inhabilitacion` / `incompatibilidad` / `sancion_vigente`: condiciones que impiden
  participar.
- `capacidad_minima` / `experiencia_minima` / `inscripcion_registro`: umbrales o
  condiciones habilitantes de elegibilidad.
- Un ítem por requisito, aunque el texto venga en una sola oración con incisos.
- Si el requisito incluye montos o cantidades, conservarlos tal como aparecen.
- `obligatorio` es `si` solo con lenguaje explícito (debe, deberá, obligatorio).
- `momento_presentacion` y `subsanable` solo si el pliego lo explicita para ese ítem.
- Si no hay evidencia verificable, no emitas el ítem.
