# OBJETIVO
Extraer los DOCUMENTOS respaldatorios que el oferente debe presentar.
Un ítem por documento.

Esta categoría cubre papeles concretos que hay que adjuntar. Las condiciones
habilitantes (no estar inhabilitado, tener facturación mínima) van en la categoría
de restricciones de participación.

# ESQUEMA
{
  "documentos_requeridos": [
    {
      "tipo": "legal|tecnico|economico_financiero|administrativo|experiencia",
      "valor": <nombre del documento tal como lo pide el pliego>,
      "metadata": {
        "obligatorio": "si|no|no_especificado",
        "momento_presentacion": "con_la_oferta|previo_apertura|pre_adjudicacion|post_adjudicacion|no_especificado",
        "subsanable": "si|no|no_especificado"
      },
      "confidence": <número calculado según la rúbrica del sistema>,
      "source_references": [
        {
          "document_id": <valor exacto del header del fragmento>,
          "page_number": <valor exacto del header del fragmento>,
          "citation": <subcadena literal del fragmento>
        }
      ],
      "extraction_status": "success|partial|not_applicable|not_found"
    }
  ]
}

# REGLAS ESPECÍFICAS
- `tipo` sale del enum cerrado, nunca texto libre. Guía de asignación:
  - `legal`: estatuto social, poder del firmante, acta de designación de autoridades,
    constancia de inscripción en registro de proveedores.
  - `economico_financiero`: balances, estados contables, referencias bancarias,
    constancia de CUIT, certificado fiscal para contratar, libre deuda previsional.
  - `tecnico`: fichas técnicas, folletos, certificaciones de producto, plan de trabajo,
    certificados ISO.
  - `experiencia`: antecedentes, nómina de contratos similares, certificados de obra,
    cartas de referencia de clientes.
  - `administrativo`: nota de presentación, constitución de domicilio, aceptación de
    condiciones, formularios de contacto.
  Si dudás entre dos, elegí el más específico y bajá `confidence` en 0.1.
- `obligatorio`: `"si"` con lenguaje imperativo ("deberá acompañar", "es requisito
  ineludible"). `"no"` si el pliego lo marca como opcional o "de corresponder".
  Sin indicación → `"no_especificado"`.
- `momento_presentacion`: solo si el pliego lo especifica. "junto con la oferta" →
  `con_la_oferta`. "el adjudicatario deberá presentar" → `post_adjudicacion`.
  "previo a la adjudicación" → `pre_adjudicacion`.
- Un ítem por documento, aunque el pliego los enumere en una sola oración separada
  por comas o punto y coma.
- Listados en tabla → un ítem por fila, `citation` con
  `Encabezado: <col> | Fila: <fila> | Valor: <valor>`.
